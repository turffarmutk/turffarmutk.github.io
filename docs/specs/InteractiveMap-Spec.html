Interactive Map

The shared backbone of the app — an uploaded aerial of the farm with tappable plots carrying their mower, cut height, restrictions, and trial pins. Read by tasks, field-ops, inventory, and trials; this is the map they all point to.

1. What this module does

The map is where the farm's geography lives. It's an uploaded aerial image with the plots overlaid as tappable regions, and each plot carries data — which mower cuts it, its cut height, any active restrictions, and the trials pinned inside it. Other modules read this map: tasks and field-ops use it to pick where work happened, inventory uses it for spray locations and treated area, and trials place their pins and restrictions here. Get this right and the whole app clicks together.

3. Base map & plots

The base is an aerial image Bill uploads — no GPS or satellite service, just the picture of the farm. The uploaded aerial already shows the plot numbering and all plots traced, which is the guide for setup: each plot is turned into a tappable region over the image with its number/name. Regions and pins are stored as coordinates relative to the image, so nothing depends on real-world GPS. The outdoor aerial is a single image and won't be replaced unless the farm expands.

Indoor research plots — a linked second map

Indoor plots get their own separate aerial. On the main (outdoor) map, the building is a selectable region — tapping it opens the indoor aerial, which behaves like the main map (tappable indoor plots, restrictions, pins). The two maps are linked: main → building → indoor.

Reminder — what a "plot" is: a turf area of one grass type; trials and restrictions live inside plots. Non-plot spots (alleyways, borders) are handled with labeled pins (§7).

4. Plot attributes

Each plot region carries the data the other modules need. Bill sets the stable ones (from the farm's existing mowing and cut-height maps):

AttributeNotes
Number / namethe plot's identifier
Regionthe tappable shape on the aerial (image coordinates)
Mower(s)which machine(s) cut this plot — powers the mowing-by-mower layer and the task view
Cut heighttarget height (shown for rotary), nullable — editable by Bill and technicians
Grass type / sizeoptional; size (sq ft) feeds treated-area math for sprays

The farm's existing "what to mow with which mower" and "cut height" maps become this per-plot data during setup — so the images turn into interactive attributes.

5. Layers & toggles

The map view has toggleable layers over the aerial:

Plots + restrictions live

Tap a plot to see its details; plots with an active restriction are flagged clearly. The always-on base interactive layer.

Mowing by mower

Pick a mower and the plots it cuts light up — the interactive version of the "what to mow" map.

Cut height

Target height per plot, shown on tap and shaded across the map (rotary).

Trial pins — colored by research group

Pins mark where trials sit, color-coded by lab so you can see each group's studies at a glance:
Brosnan  Horvath  Bowling  Sorochan  (colorblind-friendly Okabe–Ito palette). Pins also show the lab's initial, so they're distinguishable without relying on color alone. Tap a pin for the study. Dr. Stier is an administrator — no lab, no color.

6. Restrictions on the map

Restrictions (authored in Trial Protocols) render here live. Seven types — No mow, No irrigate, No fungicide, No herbicide, No insecticide, No fertilizer, No wetting agent — each on a whole plot, a spot within a plot (the trial's pin), or a non-plot area, with start/end dates. A restricted plot is visually unmistakable, so crew see it before touching that area. This is the piece that protects the research.

7. Trial pins & non-plot areas

A trial's location is a push-pin dropped anywhere on the aerial — inside a numbered plot, or on a non-plot area (alleyway, border) with a short label. Pins are colored by lab (§5). No footprint drawing — a pin marks the spot, which is enough for the crew to know where a study sits.

8. Interactions

  • Tap a plot → its details: number, mower, cut height, active restrictions, trials inside it.
  • Select plots → for tasks, field-ops, and inventory sprays (the "where" picker everywhere).
  • Drop a pin → anywhere, for a trial or a non-plot area.
  • Tap plots off → mark them done during a job; progress syncs live so a second worker sees what's left.

9. Task-contextual view (the key trick)

When a student opens a mowing task, the map doesn't show everything — it highlights only the plots that mower cuts, cutting the clutter to exactly the job at hand. For rotary mowers, each highlighted plot also shows its cut height so the machine is set right. The student then taps plots off as they finish (live progress). Restrictions still show, so they steer clear of protected areas.

10. Editing & who

  • Base & plot regions: Bill uploads the outdoor and indoor aerials and traces the plots once (plus the building link); won't change unless the farm expands.
  • Mower: Bill owns the mower assignments (mostly stable). Cut height: editable by Bill and technicians; faculty can request a change.
  • Trials & restrictions: faculty/grads/techs add them on their own-lab plots; live on the map immediately. Bill or the setter lifts a restriction.
  • Live: every add/edit reflects for everyone right away — the map is always current.

11. Screens (v1)

  1. Map — the aerial with the layer toggles (§5); tap plots/pins for detail. Default view.
  2. Plot detail — number, mower, cut height, restrictions, trials; edit controls per role.
  3. Map setup — Bill uploads the outdoor + indoor aerials, traces plot regions and the building link, sets mower + cut height. Bill only. (Techs edit cut heights from plot detail.)
  4. (Embedded) — the same map is embedded in task, field-ops, inventory, and trial screens as the picker/viewer.

13. Out of scope for v1 (comes later)

  • GPS / satellite basemap and "you are here" (v1 is an uploaded image)
  • Drawing precise trial footprint polygons (pins only)
  • Auto-segmentation of the aerial into plots (traced by hand in setup)
  • Historical map versions / time-travel
  • Measuring distances/areas by drawing on the map (plot size is a stored value)

14. Decisions

  • Plot numbering & tracing: comes from the uploaded aerial — one aerial shows all plots numbered and traced; it's the setup guide.
  • Single outdoor aerial: one image, not replaced unless the farm expands.
  • Lab colors: a colorblind-friendly palette (Okabe–Ito) for Brosnan, Horvath, Bowling, and Sorochan, and pins also carry the lab's initial so color isn't the only cue. Dr. Stier is an administrator — no lab, no color.
  • Cut heights: editable by Bill and technicians (faculty can request).
  • Indoor research plots: a separate uploaded aerial; the building on the main map is selectable and opens the indoor map (main → building → indoor).
